# Francis Ignacio — Portfolio

Public source code for [francisdotmd.page](https://francisdotmd.page), the personal portfolio of Francis Ignacio.

This repository is public for transparency and reference. It contains one personal site and is not a starter kit, theme, or content-configurable portfolio template.

## Documentation

The root README is intentionally brief. Technical documentation lives in [`.docs/`](.docs/):

- [Documentation index](.docs/README.md)
- [Development](.docs/development.md)
- [Deployment](.docs/deployment.md)

## Repository scope

Personal copy, links, imagery, analytics, and deployment configuration are specific to this site. Issues and pull requests may document changes to the site, but this repository does not promise compatibility as a reusable portfolio builder.
